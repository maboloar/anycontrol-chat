I: w-impl-details
Q: 가림 뒤 다시 찾을 때 어떤 기준으로 같은 물건인지 판단해요? 임계값도 알려 주세요
V: 색 히스토그램을 써요 / 임베딩으로 재식별하나요 / 재획득 임계값이 얼마예요 / 오탐은 어떻게 막아요 / 다시 찾기 알고리즘을 자세히 / 형상 모멘트를 써요
EQ: How does it decide it is the same object when finding it again? What are the thresholds?
EV: Does it use a color histogram? / Does it re-identify with embeddings? / What is the re-acquisition threshold? / How do you prevent false positives? / Explain the re-find algorithm in detail / Does it use shape moments?
A: 임베딩(외형 벡터) 비교는 쓰지 않고, 등록할 때 저장한 모양과 색을 여러 조건으로 확인해요. 후보의 모양 겹침 0.72 이상, 색 유사도 0.6 이상, AI가 매긴 품질 0.7 이상, 크기가 예상의 0.4~2.5배 안이어야 해요. 다른 추적 물체와 절반 이상 겹치는 후보는 빼고, 상위 후보끼리 점수 차이가 0.04보다 작으면 고르지 않고, 같은 자리에서 연속 2번 합격해야 다시 붙잡아요. 이 값들은 직접 만든 시험 영상으로 정한 기본값이에요.
EA: It does not use embedding (appearance vector) comparison; it checks the shape and color saved at registration against several conditions. A candidate needs a shape overlap of at least 0.72, a color similarity of at least 0.6, an AI quality score of at least 0.7, and a size within 0.4 to 2.5 times the expected one. Candidates that overlap another tracked object by half or more are dropped, it refuses to choose when the top candidates differ by less than 0.04, and it must pass 2 times in a row at the same place before locking on. These are default values set using our own test videos.
