# AnyControl v1.8.0 — 주변 물체와 맨손을 입력 장치로

> 2026 고려대학교 × AWS AI Innovators Challenge 출품작 · 2026-10-19 갱신
> 카메라 한 대로 물체·펜·맨손의 움직임을 읽어 마우스·키보드·앱 안의 게임 입력으로 바꾸는 macOS 로컬 웹앱입니다.

## 1. 어떤 프로젝트인가요?

전용 컨트롤러를 새로 마련하는 대신 주변 소품과 손을 입력 도구로 쓰는 프로젝트입니다. 지갑으로 커서를 움직이거나, 물체의 움직임과 손 집게를 게임·단축키에 연결하거나, 평범한 펜으로 간단한 그림을 그릴 수 있습니다. 물체별 모양과 색을 기억하고, 잠시 놓친 물체를 다시 찾도록 설계했습니다.

현재 지원 대상은 **macOS 14 이상·Apple Silicon(M1 이상)**입니다. Windows/Linux용 AnyControl 입력 앱을 지원한다는 의미는 아닙니다. 별도 프로젝트인 안내 챗봇의 Windows 실행 지원과 구분해야 합니다.

| 구분 | 현재 상태 |
|---|---|
| 입력 | 등록한 일반 물체, 기본 맨손 카드, 펜(Beta) |
| 동시 물체 | 최대 6개, 프로필당 매핑 최대 64개 |
| 출력 | 앱 안의 가상 마우스·키보드·게임패드, 선택적으로 실제 macOS 마우스·키보드 |
| 실행 | Python 백엔드 + 브라우저 화면, 인식은 로컬 처리 |
| 설치 | 첫 설치·의존성 준비에는 인터넷 필요, 준비 뒤 입력 인식은 오프라인 가능 |
| 현재 배포 상태 | 소스와 문서는 v1.8.0. 이번 갱신에서 새 배포 패키지를 만들거나 업로드하지는 않음 |

## 2. 처음 쓰는 순서

1. 카메라를 흔들리지 않게 고정하고 물체와 손이 충분히 보이게 둡니다. 책상 옆 수평 카메라에는 물체 크기 기반 앞뒤 이동을, 영상 속 위치를 그대로 쓸 맨손에는 영상 XY 이동을 기본으로 사용합니다.
2. 카메라 패널에서 장치를 고릅니다. iPhone 연속성 카메라를 USB로 연결하는 방법을 권장하지만 내장 카메라나 웹캠도 선택할 수 있습니다. 기종별 성능이 같다고 보장하지 않습니다.
3. 일반 물체는 영상에서 드래그해 등록합니다. 펜은 ‘펜 (두 점)’을 고르고 펜촉 → 반대쪽 끝 순서로 클릭합니다. 맨손 카드는 등록 없이 기본 제공됩니다.
4. 마우스로 쓸 경우 마우스 패널에서 모드와 대상을 고릅니다. 버튼·게임 조작에 쓸 경우 물체/맨손 카드의 잭을 기능 잭에 연결합니다. 두 방식을 구분해서 설정할 수 있습니다.
5. 필요하면 자동 보정을 합니다. 물체를 등록하기 전에 물체 보정을 먼저 실행하는 순서는 아닙니다.
6. 앱 안의 가상 화면이나 데모에서 확인합니다. 실제 Mac 제어는 손쉬운 사용 권한을 허용하고 출력 대상에서 별도로 켜야 하며, 시작 전 3초 유예가 있습니다. 언제든 Esc로 멈춥니다.

## 3. 간단해진 보정 마법사

일반 물체와 맨손의 기본 보정은 **잠깐 정지 → 좌우 왕복 → 앞뒤 또는 영상 위아래 왕복**입니다. 단계마다 화면 중앙으로 돌아오거나 원래 자리에 놓을 필요가 없습니다. 현재 위치에서 한쪽으로 움직여 잠깐 멈추고, 그 자리에서 반대 방향으로 움직여 멈추면 됩니다. 움직임을 시작한 위치와 방향을 측정 구간별로 읽습니다.

- 맨손 기본 모드는 영상 위·아래로, 일반 물체 기본 모드는 카메라 쪽·반대쪽으로 움직입니다.
- ‘클릭·스크롤도 맞추기’를 선택하면 해당 동작 검사를 추가합니다. 선택하지 않은 클릭 설정은 그대로 유지합니다.
- 펜은 책상 접촉과 들어 올리기 검사를 유지합니다. 일반 물체 빠른 보정과 같은 과정으로 간주하지 않습니다.
- 인식이 끊기면 유효 관측을 더 모으고, 부족한 동작은 다시 측정하거나 건너뛸 수 있습니다. 건너뛴 설정은 기존 값을 유지합니다.
- 측정 결과를 보고 적용합니다. 취소하면 이전 설정을 보존하며 측정 중에는 입력 출력을 억제합니다. 실제 전체 소요 시간은 사용자와 인식 상태에 따라 달라집니다.

## 4. 물체 마우스와 맨손 마우스

### 물체 마우스

물체를 좌우로 움직이면 커서도 좌우로, 카메라에 가깝게/멀게 움직이면 커서는 위아래로 갑니다. 앞뒤 입력의 기본은 물체가 화면에서 커지고 작아지는 변화입니다. 깊이 추정 모델은 선택 기능이며, 기본이라고 설명하면 안 됩니다. 물체 아래쪽 기준점을 따르는 방법과 튐 억제도 사용합니다.

물체 마우스의 손가락 내림 클릭은 물체와 손의 가림에 민감합니다. 현재 화면에는 이전의 자동 ‘한 손 하이브리드’ 모드가 제공되지 않습니다. 물체 이동과 맨손 버튼 매핑을 각각 구성할 수는 있지만 물체를 놓으면 자동으로 모드를 전환한다고 설명하지 않습니다.

### 맨손 마우스

| 동작 | 입력 |
|---|---|
| 손바닥을 영상에서 좌우·위아래 이동 | 영상 XY에 대응하는 커서 이동 |
| 엄지+검지 끝 집게 | 왼쪽 누름, 유지하며 이동하면 드래그 |
| 엄지+중지 끝 집게 | 오른쪽 누름 |
| 검지·중지만 펴고 엄지·약지·새끼를 접은 채 위아래 이동 | 스크롤 |

가려진 엄지나 손끝은 잘못 추정될 수 있으므로 손바닥과 손가락을 카메라에 보여 줍니다. 집게 민감도·이동 감도는 조절할 수 있습니다. 화면 위치로 움직이는 기본 맨손 모드와, 책상 위 내림 클릭/깊이 이동의 고급 대체 옵션을 혼동하지 않습니다.

## 5. 잭 연결과 맨손 버튼

물체 카드와 맨손 카드에 원형 잭이 있습니다. 카드 잭에서 기능 잭으로 끌어 놓거나 양쪽을 한 번씩 눌러 연결합니다. 기능 잭 하나에는 연결 하나, 물체 하나에는 여러 기능을 연결할 수 있습니다. 케이블을 누르면 입력 종류·감도·방향·사용 여부를 바꾸거나 연결을 뺍니다.

- 맨손 잭은 엄지+검지 집게를 기본 버튼으로 만들고, 케이블의 ‘집게 동작’에서 엄지+중지로 바꿀 수 있습니다. 손을 놓치면 입력을 해제합니다.
- 물체 입력은 좌우/상하/앞뒤/회전, 보이는지 여부, 손가락 터치 등을 선택할 수 있습니다. 사용자 정의 잭도 만들 수 있습니다.
- 물체 이름을 바꿔도 현재 연결을 유지합니다. 연결은 표시 이름과 분리된 물체 ID를 사용합니다.
- 프로필은 매핑 설정을 저장하는 기능입니다. 추적 물체 자체가 다음 실행에서 자동 등록된다는 뜻은 아닙니다. 저장한 프로필은 현재 등록 물체의 이름으로 연결을 다시 찾으므로 서로 구분되는 이름을 쓰는 것이 좋습니다.
- ‘매핑 전체 초기화’는 두 번 누르면 현재 매핑만 비웁니다. 물체·저장 프로필·사용자 잭은 유지합니다.

## 6. 손 검출을 필수로 하는 물체 터치

이전에는 물체 모습의 살색 변화만으로 눌림이 켜질 수 있었습니다. 현재는 **최근 인식된 손 + 물체 근처 손끝 + 그 손끝 주변 물체 외형 변화**를 함께 요구합니다. 손이 없거나 멀면 배경·살색 변화만으로 눌리지 않고, 전반적인 조명·색 변화도 걸러냅니다. 손이 사라지거나 멀어지면 누름을 해제합니다.

카메라 위의 진단 영역·변화 막대·접촉점은 고급 모드의 ‘터치 감지 표시’를 켰을 때만 보입니다. 기본 모드에서는 숨깁니다. 표시를 꺼도 실제 감지는 계속됩니다.

**한계:** 카메라 한 대의 RGB 영상만으로 물체 바로 앞 공중에서 가리는 동작과 물리적인 접촉을 완전히 구분하지는 못합니다. 오인식을 줄이는 보수적 조건이므로 손 인식 실패나 큰 가림에서는 터치를 놓칠 수 있습니다. 실제 환경별 오검출률과 지연을 보장하지 않습니다.

## 7. 겹침과 추적 복구

빠른 점 추적과 위치 예측, 비동기 AI 마스크 보정, 정지 잠금, 모양·색 기억에 의한 재획득을 조합합니다. 물체를 놓치면 입력을 정해진 방식으로 중립으로 돌리고, 다시 보이면 기억과 일치하는 후보를 연속 확인해 복구합니다.

여러 물체가 겹치면 카드에 ‘겹침’을 표시합니다. 겹친 동안과 잠깐의 회복 구간에는 상대 모습을 자기 것으로 잘못 배우지 않도록 색·외형 학습과 재분할 보정을 보류합니다. 기존 물체 간 마스크 배타 처리와 이동 추적은 유지합니다. 동일 외형 두 물체가 맞닿았다 분리되는 자동 시험을 통과했지만, 닮은 물체의 완전 가림을 해결했다고 주장하지 않습니다.

추적이 계속 어긋나면 물체를 다시 보이게 하고 ‘다시 선택’ 또는 Shift+드래그로 외형을 다시 지정합니다. 원래 이름·색·물체 ID와 연결은 유지하는 경로입니다.

## 9. 화면·부스 운영·초기화

패널 제목 줄을 끌어 열과 순서를 바꿀 수 있습니다. ‘배치 초기화’는 배치·크기·최소화·글씨 크기를 복원하는 화면 전용 동작입니다. 영상 표시 반전과 전체 입력 반전은 별개이며 둘 다 기본 모드에서 접근할 수 있습니다. 기본 성능 패널에는 카메라/처리/미리보기 fps, 처리·화면 지연, 왕복 시간과 입력 상태를 표시합니다.

어두운 빨간 **‘모든 세팅 초기화’**는 두 번 눌러 실행합니다. 등록 물체·펜·현재 매핑·입력/추적/보정/화면 상태를 비우고 실제 출력을 끕니다. **저장 프로필·사용자 정의 잭·현재 카메라 연결/해상도/FPS는 보존**합니다. 대기 중인 이전 매핑 저장이 초기화 뒤 연결을 되살리지 않도록 저장 순서도 보호합니다.

무입력 시연 화면의 기본 대기는 **120초**이며, 진입할 때 동일한 전체 초기화를 한 번 실행합니다. 포인터·키보드 입력이나 사람 접근 감지로 체험 화면으로 복귀합니다. 기본 대기값과 자동 초기화는 부스에서 다음 관람객이 이전 설정을 이어받지 않게 하기 위한 기능입니다.

## 10. 안전·프라이버시·실행 조건

- 인식은 로컬에서 처리합니다. 초기 설치와 모델·의존성 준비에는 인터넷이 필요할 수 있습니다.
- 기본은 앱 안의 가상 입력입니다. 실제 Mac 제어는 권한과 활성화가 필요하며 Esc는 긴급 정지입니다.
- 모델과 UI가 준비된 뒤 사용할 수 있습니다. 카메라 권한과 손쉬운 사용 권한은 서로 다른 권한입니다.
- Apple Vision을 기본 손 엔진으로 사용하고, 지원 환경에서 MediaPipe를 선택할 수 있습니다. 손 인식을 껐다고 카메라 전체가 꺼지는 것은 아닙니다.
- 메모리 8GB 이상, 첫 설치 디스크 여유 공간 4GB 이상이 안내된 요구사항입니다. 실제 반응은 카메라·물체 수·설정에 영향을 받습니다.
- 앱 탭을 닫으면 종료 유예 뒤 카메라와 눌린 입력을 해제합니다. 새 창이 연결을 인계받는 경우 예전 창은 연결을 놓습니다.

## 11. 검증과 한계

코드·API·화면 자동 검사와 별도 합성 카메라 브라우저 흐름으로 동작을 검증합니다. 과거 자체 합성 영상 50편에서 기록한 추적 성공 약 39% 대 약 89% 비교는 **그때의 시험 조건에 한정된 결과**입니다. v1.8.0에서 모든 성능 벤치를 다시 측정한 결과도, 모든 실제 환경의 정확도도 아닙니다. 최신 연구와 공정한 공동 데이터셋 비교, 실제 장애 사용자 평가, 실제 OS 장시간 제어, 다양한 카메라·조명·완전 가림 검증은 별도 과제입니다.

이번 갱신의 보정 간소화는 현장 조작 부담을 줄이는 구현 변경입니다. 실제 사용자별 보정 시간·성공률은 측정하지 않았습니다. 터치와 겹침 개선 역시 오검출이나 ID 바뀜이 없다는 보장이 아닙니다. 검증된 구현, 제한된 측정, 아직 확인하지 않은 활용 가능성을 구분합니다.
